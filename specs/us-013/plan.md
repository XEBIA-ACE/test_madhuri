Implementation involves adding a new entry point on the HRIS login page that triggers the SSO process. The front-end will be updated to display a "Sign in with SSO" button, while back-end configurations will manage the authentication process with fixed URIs provided by the identity provider. Configuration settings for the identity provider will be accessed from the environment to enhance security and flexibility, allowing changes without code redeployment. Files to update include `src/AuthenticationService/Program.cs` to load identity provider configurations and service registrations, and `src/AuthenticationService/Controllers/AuthenticationController.cs` for handling the SSO login requests.
